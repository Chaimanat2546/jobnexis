## วิธีรันโปรเจกต์นี้

1. ติดตั้ง Docker
2. clone repo:
   git clone https://github.com/your-team/your-project.git
3. สร้างไฟล์ .env:
   cp .env.example .env
4. รัน:
   ./vendor/bin/sail up -d
5. รัน migrate:
   ./vendor/bin/sail artisan migrate
